Summary

FrequencyMask provides static methods for evaluating parametric frequency masks over a frequency grid. It implements Gaussian and super Gaussian variants and includes a unified evaluate method that dispatches on mask parameter objects for consistent use throughout the receptive field masking pipeline.
Key features:
  • Generates Gaussian frequency masks over a specified band using configurable mask parameters.
  • Provides super-Gaussian frequency masks with a tunable shape exponent for sharper or flatter profiles.
  • Ensures symmetric masks centered on the band’s center frequency.
  • Supports optional normalization of Gaussian masks.
  • Provides a unified evaluation interface via parameter objects to enable consistent mask generation across the SFRFs pipeline.
  • Enforces input validation to ensure consistency and physical interpretability.
This class provides a compact and extensible foundation for SFRFs processing (see Reference [1]).

Description

FrequencyMask is a lightweight static utility class for constructing frequency-domain gain functions. It supports Gaussian and super-Gaussian profiles, enabling smooth or sharp spectral weighting depending on the chosen mask parameters. Masks are defined symmetrically around the center frequency of a specified band. In the Gaussian case, the mask width is derived from the band limits via the associated mask-parameter object and may optionally be normalized. In the super-Gaussian case, the mask shape is controlled by an exponent that interpolates between Gaussian-like and near-rectangular profiles, with the scale parameter constrained by the band definition to ensure physical consistency.

Methods

gaussian

Generates a Gaussian frequency-domain mask over a specified band.
Syntax
  • G = FrequencyMask.gaussian(f, band)
  • G = FrequencyMask.gaussian(f, band, sigmaRule)
  • G = FrequencyMask.gaussian(f, band, sigmaRule, normalize)
Parameters
Name
Type
Description
f
double column vector
Frequency axis in Hz.
band
1×2 double
Two-element vector [fMin, fMax] defining the band in Hz.
sigmaRule
double, optional
The sigma rule determines how the limits of the frequency bands are handled. A sigma rule of 3 corresponds to 99.7% of the area under the Gaussian falling within the specified frequency band. Default is 3. See SFRFsParameters.
normalize
logical, optional
If true, normalizes the mask such that its area equals 1. Default is false.
Output
Name
Type
Description
G
double column vector
Gaussian mask evaluated over f.

superGauss

Generates a super-Gaussian frequency-domain mask over a specified band.
Syntax
  • G = FrequencyMask.superGauss(f, band, alpha, beta)
Parameters
Name
Type
Description
f
double column vector
Frequency axis in Hz.
band
1×2 double
Two-element vector [fMin, fMax] defining the band in Hz.
alpha
positive double
Scale parameter controlling the width of the super-Gaussian profile. Must equal (band(2) - band(1)) / 2 to ensure consistency with the band definition.
beta
positive double
Shape exponent controlling the profile of the mask: • beta = 1 : Laplacian-like • beta = 2 : Gaussian • beta > 2 : Flatter top • beta >> 2 : Near-rectangular
Output
Name
Type
Description
G
double column vector
Super-Gaussian mask evaluated over f.

evaluate (recommended)

The method evaluate provides a unified entry point for frequency-mask construction based on parameter objects. The method dispatches internally according to the concrete type of maskParams, invoking the appropriate mask generator with validated parameters derived from the object. This interface is the preferred mechanism for mask generation within the SFRFs pipeline, as it decouples mask evaluation from specific functional forms and enables consistent extension to additional mask types without changing downstream code.
Syntax
  • G = FrequencyMask.evaluate(f, band, maskParams)
Parameters
Name
Type
Description
f
double column vector
Frequency axis in Hz.
band
1×2 double
Two-element vector [fMin, fMax] defining the band in Hz.
maskParams

Mask-parameter object defining the mask type and configuration (e.g., GaussianMaskParameters, SuperGaussianMaskParameters).

Example

Gaussian profiles

 
% Frequency vector (Hz)
f = linspace(0, 200, 1000)';
 
% Monitoring band [fMin fMax]
band = [80 120];
 
% Generate Gaussian masks with different sigma rules
G_half = FrequencyMask.gaussian(f, band, 0.5);
G_one = FrequencyMask.gaussian(f, band, 1);
G_two = FrequencyMask.gaussian(f, band, 2);
 
% Plot
figure
plot(f, G_half); hold on
plot(f, G_one)
plot(f, G_two)
grid on
 
xlabel('Frequency (Hz)')
ylabel('Amplitude')
title('Gaussian masks for different \kappa_\sigma')
 
legend( ...
'\kappa_\sigma = 0.5', ...
'\kappa_\sigma = 1', ...
'\kappa_\sigma = 2', ...
'Location','northeast');

Super-Gaussian profiles

% Frequency axis
f = linspace(0, 200, 2048).';
 
% Center frequency (fixed)
fc = 100;
 
% Half-widths to compare (these are the implied alphas)
alphas = [1, 2, 4];
 
% Shape exponent (fixed)
beta = 8;
 
figure;
hold on;
 
for a = alphas
band = [fc - a, fc + a];
G = FrequencyMask.superGauss(f, band, a, beta);
plot(f, G, 'DisplayName', "\alpha = " + a + ", band = [" + ...
band(1) + ", " + band(2) + "]");
end
 
hold off;
grid on;
xlabel("Frequency (Hz)");
ylabel("Gain");
title("Super-Gaussian Masks (varying band width / \alpha, fixed \beta = 8)");
legend("Location", "northeast");
xlim([94,106])

Super-Gaussian with mask parameters (recommended usage)

% Frequency axis
f = linspace(0, 200, 2048).';
 
% Frequency band
band = [80 120];
 
% Alpha fixed by band definition
alpha = (band(2) - band(1)) / 2;
 
% Beta values to compare
betas = [0.25, 1, 2, 10];
 
figure;
hold on;
 
for b = betas
maskParams = SuperGaussianMaskParameters( ...
alpha = alpha, ...
beta = b);
 
G = FrequencyMask.evaluate(f, band, maskParams);
plot(f, G, 'DisplayName', "\beta = " + b);
end
 
hold off;
grid on;
xlabel("Frequency (Hz)");
ylabel("Gain");
title("Super-Gaussian Masks via evaluate (varying \beta)");
legend("Location", "northeast");
